## 实现与限制

- JS/TS/TSX 使用 Tree-sitter 静态语法树，提取声明、成员、箭头函数绑定、属性键、模块声明、调用及候选路由。符号带行号；导入、导出与跨语言调用不宣称运行时已解析。
- YAML 用仅构造节点的 BaseLoader 并限制事件数量、嵌套和别名，JSON 另经 JSON 语法解析；字段路径和行号可回读。结构反映配置存在，不代表启用、最大能力或实现完成。JSONC 未启用。
- Markdown 按井号标题及行数分块；普通文本、Shell、Dockerfile、Makefile、Lua、Protobuf、配置等仅受控分块。角色依据路径、文件名标记示例、历史、计划等；无法可靠判断的说明文档不认定为已实现能力。SQL、XML、INI 等仅提供文本模式；未提供 C/C++、模板或任意无扩展名文件的语义解析。
- 补建对整批清单、数据库记录及未排除文件物理哈希作核验，仅增强旧 unsupported 且非敏感记录。单事务、暂存状态、快照及品类锁，不改原文件 ID，不删除既有证据。故障注入验证后段错误可回滚。既有通用 build 仍为初次构建入口，不用它强制重置旧库状态。
- 解析错误和资源限制保留独立状态；未检索到结果不可作为不支持证据。技术测试未证明敏感识别能发现所有未知格式的秘密。
