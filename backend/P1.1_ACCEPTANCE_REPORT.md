PostgreSQL 16.9、Redis 7.4.4（容器），RQ 2.3.3。

初始 pytest 为 49 passed / 3 failed；根因是 macOS 不允许重命名已只读的临时根目录，

另一次基础设施脚本最初直接按路径运行找不到 app 包，改用文档中模块入口后通过。
初始日志保留，未伪造成首次即全部通过。

- Starlette 测试客户端使用 AnyIO 已弃用类型别名。

## 3. 真实样例与指标

输入：tests/fixtures/demo_waf_source.zip，由 scripts/generate_fixtures.py 人工编写、可复现生成。
真实任务 ID：d44e8d69-8982-425f-b157-b82c046023d5。
真实快照 ID：93f4f054-3ee7-444b-97a0-feebb5f02a8f。

流程：管理员上传 → 202 → 数据库 queued → 真实 Redis/RQ SimpleWorker →
路径/资源/内容检查 → 隔离解压及逐文件 SHA-256 → succeeded，stage=extracted。

本次 1492 字节 ZIP，展开 882 字节，4 个文件保留、2 个依赖/二进制文件排除；
处理耗时 12 ms；模型请求 0，Agent 工具调用 0，Token 0，模型成本 0，
model_mode=NOT_USED。不是 Mock 模型，也不是业务能力发现结果。
该耗时不包含排队及网络传输，不是 P50/P95 或真实项目性能承诺。

非法 ZIP：
- Zip Slip → UNSAFE_PATH
- 符号链接 → LINK_OR_SPECIAL_FILE
- 压缩炸弹 → COMPRESSION_RATIO_EXCEEDED
真实重试后仍失败、attempt=2，不伪装修复不可变输入。

证据 ID / 能力记录为 NOT_IMPLEMENTED；文件 manifest 是导入元数据，不能冒充证据。
规格 13.2 的完整“输入→工具→证据→能力”样例将在 P1.3 后提供。
