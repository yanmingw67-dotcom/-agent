基线8ac419b。依据原始设计书第4/6/8/9/12章及复核A13-01～05。
只实现能力质量/断言证据、去重关系、人工审核、覆盖与原子发布回滚；不进入P1.5/Probe或Agent B。

1. 原CapabilityClaim/draft_json与模型轨迹不可改写；新增不可变审核修订、review_events、发布清单。
   类型product_function/technical_mechanism/investigation_action/invalid/unknown；机器规则只能降级/阻断，不能自动approved。
2. 修订必须逐字段拆分断言：name/action/target/business_goal/mechanism及所有scope/conditions/limitations。
   每条显式关联同快照真实证据、人工语义结论及说明；跨函数依赖逐项登记被调方证据。
   高风险承诺（持久/原子/幂等/隔离/配置范围）需明确实现链证据与人工保证边界，未闭合不得发布。
   源码有效只作来源核验，不自动推导语义；受限正则仅作防线，不能宣称完整语义校验。
3. 修改生成新修订并失去旧批准，不覆盖原稿；接受仅admin显式人工操作，模型无该工具。
   return/reject/modify/accept均审计，乐观expected_revision防止过期审核；产品功能还须入口接线证据。
4. 重复配对只建议，合并必须same_as且action/target/goal/机制/范围/条件/限制边界一致，
   不做范围并集；保持来源谱系；其他关系独立人工核验并保留hypothesis。
5. 发布选择显式审核通过修订，冻结payload/关系/覆盖缺口；事务内再次核对所有来源哈希/门槛，
   同时切换category active_publication_id和active_snapshot_id，expected_active防并发覆盖。
   缺口须显式确认，不得把部分覆盖假装完成；错误审核/失效证据/在途任务阻断，失败保留旧指针。
   rollback只切换同品类已发布不可变清单，重验来源，写切换记录；普通读取无版本选择。
6. 修复正常fragment_budget/task_budget/dependency_gap与真实failed区分；旧失败恢复兼容。
7. 新≥16文件配置/API/回调/接线线索人工仓库，静态检查不执行上传源码。
   使用P1.3真实候选作人工审核案例，调查动作退回；持久断言无底层证据拒绝；
   窄化为真实委托/本地机制后人工确认，保留原文。此阶段不需要额外收费模型重跑。
8. 原161项原文保留；新增隔离/权限/过期审核/无证据/跨调用/错误合并/关系类型/失效证据/
   事务失败/发布回滚/读取快照一致性/覆盖/预算停止回归，真实PG/API执行同样门槛。

   交付真实API/PG审核发布回滚记录、测试与报告；本地提交，不默认推送；结束暂停。
