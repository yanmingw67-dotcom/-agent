## 本批

1. 兼容迁移0005，新增不可变证据、能力草稿/证据链接/候选关系、模块调查检查点与脱敏轨迹。
2. 固定服务端RunContext，证据登记回读真实源码/文档、核对哈希/范围/快照；只标来源核验，
   不将内容真实等同于语义已证明。模型输出只允许candidate/evidence_found。
3. Pydantic AI模块调查工具使用原ReadOnlyTools，不暴露Shell/文件写入/任意网络；
   文档/源码指令是数据。入口/模块/文档批量预调查，记录未解释入口、覆盖缺口及预算耗尽。
4. 独立builder队列/Worker，默认单并发；每模块事务检查点，已完成模块不重复生成，
   重试保留审计与已核验证据；请求/工具/Token/字符/时间预算，模型超时/失败可恢复。
5. 管理员后台异步调查与候选/证据查询，不改变原build仅索引的接口语义，
   不向普通read开放暂存知识，不实现发布/审批/Probe/Agent B。
6. 新测试独立文件，保留原115项；FunctionModel仅为无外网测试，真实模型另做显式授权验收；
   保存实际工具轨迹、使用量和费用口径，不记录完整提示/源码/模型推理正文。

## 资源与模型准入

保留独立retrieval通道，七服务总CPU仍控制4核，内存预算<=8GiB；
builder只读源码/文档，不挂载归档。目标独立4C8G环境未提供，不冒称已验证。
模型接入采用可替换Pydantic AI Model，先交付OpenAI兼容内网/批准端点适配，
显式BUILDER_MODEL/BASE_URL/API_KEY与准入开关；不自动使用工具宿主的模型凭据。
初始环境未配置，任务已实际记录MODEL_NOT_CONFIGURED；随后用户提供批准端点与模型，
本地安全配置并仅授权人工公开资产，企业数据外发保持关闭。真实模型验收结果见交付报告；
无配置时任务明确失败MODEL_NOT_CONFIGURED/未授权，禁止自动降级为Mock冒充成功。
费用按配置价格与实测Token计算，价格未知为null而非0。
