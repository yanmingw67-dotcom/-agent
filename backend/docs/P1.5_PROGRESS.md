1. **Probe 契约**：`POST /api/v1/probes`，仅接受 category_id、单条 requirement_text、
   有界 limit；额外字段/查询参数/空白/越界拒绝。
2. **只读一致性**：每请求独立 PostgreSQL `REPEATABLE READ READ ONLY` 事务；
   绑定品类当前发布/快照双指针；真实 PG 测试覆盖发布切换与只读拒写。
3. **发布与证据校验**：清单哈希、作用域、快照状态、修订新鲜度、证据来源/引文哈希；

4. **检索边界**：确定性词法匹配；不调用模型；无合规/满足/等效结论；
   `formal_compliance_decision=null`、`support_status=not_assessed`。

   检索服务无审核/上传/发布/回滚写路由；文档卷只读挂载。
