## 功能与操作

管理员在部署机访问 http://127.0.0.1:18180/#/admin/categories/69659364-0781-4038-abc7-d01f3dfa6594 ，使用既有管理员令牌。回环地址不能直接作为远程访问地址。

1. 在概览中的「资料来源与派生链」查看服务端核验结果。只有合法链才显示已通过；异常显示错误码，不能以相同哈希代替链核验。
2. 在源码根快照区域核对品类、根快照 ID、状态和完整 SHA-256，可复制完整哈希。点击「确认源码来源」，手动填写来源说明、适用范围、确认依据；不允许输入任意目标快照 ID，也不预填来源或授权编号。
3. 在「技术文档」中，仅正式企业文档、解析状态 parsed、有效分段数大于零且所属快照就绪时允许确认。目标品类、快照和文档 ID 由当前记录绑定；不满足门槛时显示具体原因。
4. 「资料来源确认」标签页展示当前品类全部记录，支持展开完整详情，包括确认人、时间、状态和撤销信息。撤销需要二次确认，执行后重新读取后端记录；刷新失败不会伪装为同步成功。
5. 403、404、409、422、网络异常及哈希或关联不匹配均显示错误信息。普通用户权限仍由原后端校验。资料来源确认不是外部模型授权，也不会自动发布。

字段去除首尾空白后校验：来源说明 3–500 字符、适用范围 8–1000 字符、确认依据 3–200 字符。真实说明和依据由管理员自行审核填写。
