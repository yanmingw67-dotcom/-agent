# P2.3 验收报告：评估结果工作台、人工复核与 Word/Excel 导出

- 验收对象：P2.3 增量交付
- 基线提交：`210967a`
- 验收日期：2026-11-19
- 验收环境：macOS（darwin 25.3.0）、Python 3.12、SQLite 测试库、PostgreSQL 16.9 临时容器、Node.js 22.22.1
- 结论摘要：代码、合成数据自动化测试、真实 PostgreSQL 专项、前端类型检查/构建与浏览器联调均完成；真实 WAF 业务能力未验收，不得据此宣称真实产品能力通过；未进入 P3.1。

## 一、结论

### 1. 已通过

- P2.3 工作台 API、人工复核只追加、固定发布证据、Word/Excel 导出与受控下载已实现。
- 合成数据下，定向测试 10 项、全量回归 412 项、PostgreSQL 专项 1 项通过；前端类型检查与构建通过；Ruff 全绿。
- 浏览器中完成“登录 → 任务列表 → 结果页 → 人工复核 → 计数刷新 → 导出下载请求”的实际操作。
- 人工复核未修改 P2.2 自动结论、原子判断或证据行；旧复核记录保留。
- 其他用户与管理员不能读取、复核或导出目标任务。
- 发布内容被篡改时，证据标记不可用，导出失败关闭，不生成含编造证据的文件。
- Word 表格可编辑；Excel 无公式单元格，公式前缀文本被转义。

### 2. 未通过 / 未验收

- **真实业务能力未验收**：没有真实雷池 WAF 源码、真实产品技术文档、真实《WAF招标技术参数表.docx》和授权企业模型。
- **真实多用户账号体系未验收**：当前只复用既有 Token 身份映射，没有账号、角色、组织架构管理。
- **生产部署未验收**：未做生产反向代理、TLS、容量、并发、备份恢复和正式安全渗透。
- **多浏览器兼容性未验收**：只在当前内置浏览器完成联调。
- **P3.1 未启动**，不在本次交付范围。

因此，本轮可提交人工代码审核与合成环境验收；不能把结果描述为“真实 WAF 产品能力验收通过”。

### 3. 验收步骤

2. 普通售前用户登录，只选择产品品类；
3. 上传真实《WAF招标技术参数表.docx》；
4. 核对提取参数、原子子要求与原文位置；
5. 启动评估，记录任务 ID、固定 `publication_id`、发布哈希、模型授权状态；

9. 由独立复核人抽查结论与证据，记录差异；
10. 记录任务级通过/失败、缺陷、风险与整改责任人。

### 4. 通过标准

- 参数提取数量与原文一致，位置可回溯；
- 每条系统结论都有固定发布证据或明确“无法确认”；
- 不出现无证据的“支持”；
- 人工复核不改变自动结论与证据；
- Word 表格可编辑，Excel 可编辑且无公式执行；
- 导出内容与页面一致；
- 下载仅限任务所有者；
- 历史任务在新发布后仍使用原固定发布；
- 真实业务验收记录由验收人签字确认。

## 十、最终意见

P2.3 的代码与合成环境验收已完成，可以进入人工代码审核。真实 WAF 能力、真实资料提取质量、真实模型判断质量、生产权限与容量均未验收；在完成独立真实业务验收前，不应对外宣称“真实 WAF 参数评估能力通过”，也不应启动 P3.1。
