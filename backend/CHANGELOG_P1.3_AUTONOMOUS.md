# P1.3补充开发：Agent A自主源码探索调度

基线90e5a21。只增强Agent A，不开发P1.4、Agent B、能力合并或发布。

## 本轮变更

- 新autonomous.py：模块元数据与不可信文档线索构建优先frontier；模型选择调查顺序、
  提出搜索词和函数追踪；共享只读检索返回真实定位后才加入调查，允许同快照跨模块扩展。
- 从索引符号实际起止行及未解释行范围生成小窗口，不再以前三文件/每文件前80行代表调查范围。
  静态元数据、队列及每轮检索均受限，截断/未执行线索显式deferred。
- 扩展bounded公共候选执行器：沿用精确回读、证据登记、候选/Link事务保存，
  支持适用范围/条件及非首行片段的下界校验；原bounded简单入口保留。
- 片段完成与候选同事务检查点；无新增候选也保存观察；哈希和行区间去重。
  重叠范围只安排尚未分析的区间；同任务跨调查重复片段可复用，记录来源，不重复模型调用。
- 基于模型反馈与引用元数据动态扩展。直接依赖优先级高于低信息量导入片段，
  按深度和模型顺序衰减，避免单条深依赖挤占同层未解释分支。
- 原8请求/30工具/30000Token/80000字符及180秒限制不增加；
  自主模式把它们同时作为整任务累计限制，retry不重置。单请求仍60秒/4000输出Token。
- budget/time/fragment限额停止partial，保留任务队列、未解释入口、pending/deferred和覆盖状态；
  knowledge_build_complete=false，coverage_incomplete=true，来源真实不证明语义正确。
- 新equivalence.py：两侧源码回读后比较输入/输出/条件/异常/副作用；
  允许拒绝等效或证据不足，possible_equivalent仍hypothesis，须来自不同函数或模块。
  bounded旧后置等效入口也改用此检查器，保留假设接口但不强迫生成关系。
- investigate请求新增autonomous和exploration_max_fragments，旧默认和字段保持兼容。
- 原worker单任务互斥锁、企业分类判定、只读挂载、检索资源和4CPU/6144MiB配额不变。
- 新人工12源码文件仓库，第8文件函数位于118行；API跨模块调用、配置、文档及去重等效陷阱。
  服务端新增独立固定manifest，仍精确文件集合/哈希审批；不支持任意企业降级。
- 新增独立回归与真实验收脚本，gold只在验收后读取，收集实际轨迹、DB证据和检索延迟。
  首轮真实运行发现审计事件字段长度与优先级问题，原始结果保留并人工判不通过；
  修复后另存最终真实复验，不覆盖失败。
